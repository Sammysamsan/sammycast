# Sammy — India's AI casting stage

Mobile-first casting platform from the Sammy Product Blueprint.

## Dual apps

- **Production** — Page, Threads, AI Review, Messages, Settings
- **Talent** — Feed, My Auditions, Record, Profile, Leaderboard
